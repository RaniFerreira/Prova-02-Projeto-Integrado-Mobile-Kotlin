## 🚀 Como executar

Cada aplicativo é um projeto Android independente.


1. No Android Studio, abra **a pasta do app** que deseja rodar (não a raiz do repositório)
2. Aguarde a sincronização do Gradle
3. Rode a configuração `app` em um emulador ou dispositivo físico ▶️

> 💡 Cada pasta tem seu próprio README com detalhes, screenshots e requisitos específicos.
